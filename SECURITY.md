# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/N1CK99925/Luna/security/advisories/new).

Include a description, steps to reproduce, and the affected version or commit.
You should receive a response within 7 days.

## Supported versions

Only the latest commit on `main` is supported until the first tagged release.
